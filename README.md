# Wash & Clean Up

เว็บแอปเช็กสถานะเครื่องซักผ้า/เตารีดในหอพัก ทำขึ้นเพื่อแก้ปัญหาคลาสสิกของหอพัก — เดินไปถึงห้องซักแล้วเจอเครื่องไม่ว่างสักเครื่อง หรือเครื่องเสียแต่ไม่มีใครรู้จนกว่าจะเสียเงินเปล่า

หน้าตาออกแบบให้ใช้ง่ายบนมือถือเป็นหลัก (โทนฟ้า-กรมท่า การ์ดโค้งมน) แบ่งเป็น 3 ส่วน: หน้าสำหรับนักศึกษาดูสถานะเครื่องและแจ้งซ่อม, หน้าแอดมินจัดการเครื่อง/ดูรายรับ-รายจ่าย/รับเรื่องแจ้งซ่อม และหน้า demo ที่จำลองการหยอดเหรียญของฮาร์ดแวร์จริง (ไว้ใช้ตอนยังไม่ได้ต่อเครื่องจริง)

🔗 Live demo: https://wash-n-clean-up.vercel.app

## ฟีเจอร์หลัก

**ฝั่งนักศึกษา**
- ดูสถานะเครื่องซัก/เตารีดแบบเรียลไทม์ (ว่าง / กำลังใช้งาน / มีปัญหา) พร้อมเวลานับถอยหลัง
- แจ้งปัญหาการใช้งานเป็นขั้นตอน (เลือกเครื่อง → อาการ → รูปถ่าย → ข้อมูลผู้แจ้ง) แนบรูปได้ ระบุความรุนแรง และขอคืนเงินได้ถ้าเสียเงินไปแล้ว
- ติดตามสถานะใบแจ้งของตัวเองได้ที่ "การแจ้งของฉัน"

**ฝั่งแอดมิน**
- เพิ่ม/แก้ไข/ลบเครื่อง ตั้งราคาและเวลาใช้งาน
- หน้ารายรับ-รายจ่าย พร้อมกราฟ สรุปตามช่วงเวลา และดาวน์โหลดเป็น CSV
- จัดการใบแจ้งซ่อม ตั้งแต่รับเรื่อง → กำลังซ่อม → ซ่อมเสร็จ พร้อมบันทึกค่าซ่อมเข้ารายจ่ายอัตโนมัติ

**หน้า demo**
- จำลองการหยอดเหรียญ/เสียบปลั๊กเตารีดโดยไม่ต้องมีฮาร์ดแวร์จริง เอาไว้ทดสอบหรือโชว์ระบบ

## เทคโนโลยีที่ใช้

หน้าบ้านเป็น HTML/CSS/JavaScript ล้วน ๆ ไม่มี framework หรือ build step ใด ๆ เปิดไฟล์แล้วรันได้เลย ส่วนข้อมูลมีให้เลือก 2 แบบ:

- **โหมดออฟไลน์ (ค่าเริ่มต้น):** เก็บทุกอย่างใน `localStorage` ของเบราว์เซอร์ เหมาะกับทดลองเล่นคนเดียว
- **โหมดออนไลน์:** เชื่อมกับ **Firebase Realtime Database** + **Firebase Authentication** ทำให้ทุกเครื่อง/ทุกคนเห็นข้อมูลชุดเดียวกันแบบเรียลไทม์ (เลือกใช้ Realtime Database เพราะสถานะเครื่องต้องอัปเดตทันที และยังต่อกับบอร์ดจริงอย่าง ESP32 ผ่าน REST API ได้ในอนาคต)

โฮสต์อยู่บน **Vercel** เพราะเป็นเว็บ static ล้วน ๆ ไม่ต้อง build

## โครงสร้างไฟล์

```
washnclean-up/
├── index.html            หน้าแรก เลือกเข้าใช้งานแบบนักศึกษาหรือแอดมิน
├── landing.css
├── shared-data.js        ชั้นข้อมูลกลาง (เครื่อง, ใบแจ้งซ่อม, บัญชีแอดมิน)
├── icons.js              ชุดไอคอน SVG ที่ใช้ร่วมกันทุกหน้า
├── firebase-config.js    ใส่ค่า config ของ Firebase ที่นี่ (ปล่อย null = โหมดออฟไลน์)
├── firebase-sync.js      ซิงก์ข้อมูลกับ Firebase เมื่อตั้งค่าไว้
├── database.rules.json   กฎความปลอดภัยของ Realtime Database
├── vercel.json           ตั้งค่าตอนขึ้นโฮสต์บน Vercel
├── vendor/firebase/      Firebase JS SDK (เก็บไว้ในโปรเจกต์ ไม่ต้องพึ่ง CDN)
├── student/              หน้าฝั่งนักศึกษา
├── admin/                หน้าฝั่งแอดมิน
└── demo/                 หน้าจำลองฮาร์ดแวร์
```

## รันดูในเครื่องตัวเอง

ต้องรันผ่านเว็บเซิร์ฟเวอร์เล็ก ๆ (ไม่ใช่ดับเบิลคลิกเปิดไฟล์ตรง ๆ) ไม่งั้น `localStorage` จะทำงานไม่ถูกต้องข้ามหน้า:

```bash
git clone https://github.com/NFDOG/WashNcleanUP.git
cd WashNcleanUP
python3 -m http.server 8000
```

แล้วเปิด `http://localhost:8000/index.html`

บัญชีแอดมินสำหรับทดลอง (โหมดออฟไลน์): **admin / admin**

## ต่อกับ Firebase (ถ้าอยากให้ข้อมูลเรียลไทม์จริง)

1. สร้างโปรเจกต์ใหม่ที่ [Firebase Console](https://console.firebase.google.com)
2. **Build → Realtime Database → Create Database** เลือก location ที่ใกล้ผู้ใช้ (เช่น Singapore) และเลือก "Start in locked mode"
3. แท็บ **Rules** ลบของเดิมแล้ววางเนื้อหาจากไฟล์ `database.rules.json` ที่นี่แทน แล้ว Publish
4. **Build → Authentication** เปิดวิธีล็อกอิน **Email/Password** และ **Anonymous** จากนั้นสร้างผู้ใช้แอดมินด้วยอีเมล/รหัสผ่านของตัวเอง (ดูรายละเอียดเรื่องรหัสผ่านในคอมเมนต์ของ `firebase-config.js`)
5. ปิดการสมัครสมาชิกเอง (Authentication → Settings → User actions → ปิด Enable create)
6. **Project settings → General → Your apps → เพิ่มเว็บแอป** แล้วคัดลอก `firebaseConfig` มาวางแทน `null` ใน `firebase-config.js`
7. ถ้าเปลี่ยนอีเมลแอดมิน ต้องแก้ให้ตรงกันทั้งใน `WCU_ADMIN_EMAILS` (`firebase-config.js`) และทุกจุดที่อ้างอีเมลใน `database.rules.json`

พอเชื่อมสำเร็จ แอดมินที่ล็อกอินเข้ามาคนแรกจะได้ข้อมูลตั้งต้นให้อัตโนมัติ (เครื่อง 10 เครื่อง + ตัวอย่างข้อมูล) ลบข้อมูลตัวอย่างได้ทีหลังจากหน้ารายรับ

**⚠️ อย่า commit ค่า `firebaseConfig` จริงของตัวเองขึ้น GitHub** — เก็บไว้แค่ในเครื่อง/บนโฮสต์ที่ deploy จริงเท่านั้น

## ขึ้นโฮสต์บน Vercel

```bash
npx vercel          # ครั้งแรกจะให้ล็อกอินและตั้งชื่อโปรเจกต์
npx vercel --prod   # ขึ้นเว็บจริง
```

หรือจะ import repository นี้เข้า [vercel.com/new](https://vercel.com/new) โดยตรงก็ได้ (Framework Preset เลือก "Other" ไม่ต้องตั้ง Build Command) หลัง deploy แล้วอย่าลืมเพิ่มโดเมนที่ได้ลงใน Authentication → Settings → Authorized domains ด้วย ถ้าใช้โหมด Firebase

- ฟอนต์ (Baloo 2 / IBM Plex Sans Thai) โหลดจาก Google Fonts ถ้าออฟไลน์ตอนเปิดหน้าเว็บจะ fallback ไปฟอนต์ระบบแทน
